# Norby 第一版規格

狀態：產品決策已確認；開發及官方連線驗證分開追蹤。2026-11-04。

## 已確認的產品範圍

- 新平台是 Norby 的主要平台，已部署於 www.norby.tw；沒有舊客戶、案件或文件需要遷移。
- 繁體中文與英文。客戶可直接在網站申請，或授權外部 agent 經 API / MCP 辦理；共用案件與驗證規則。
- 外部 agent 採登入授權，可撤銷。付款確認、最終審核、退款確認、證書核對均由 Norby 員工操作。
- 接受自然人股東（可多人）的香港私人股份有限公司，使用標準章程。
- 單一方案：設立代辦、首年公司秘書、首年香港註冊地址。銀行開戶與 Stripe 保留諮詢入口，由 Norby 人工承接。
- Norby 引導需要簽署的客戶登記官方帳戶並完成身分核實。Norby KYC / AML 審核與官方帳戶核實分開。

## 收款與退款

| 幣別 | 收款公司 | 定價 |
| --- | --- | --- |
| HKD | 香港公司 | 獨立固定價格 |
| USD | 香港公司 | 獨立固定價格 |
| TWD | 台灣公司 | 獨立固定未稅價格，服務費與代收政府費用合計另加 5% 營業稅 |

上述 5% 是用戶指定的業務設定，不代表本文件完成跨境稅務判定。

銀行轉帳；Norby 確認實際入帳後才開始人工審核。上傳憑證不等於入帳。服務費、代收政府費、稅額分項列示；報價保留不可變的版本。客戶收款與 TPSI 從 Norby 預付款帳戶扣費使用不同紀錄。

Norby 審核拒絕且確認未提交 TPSI 的案件，全額退還實收款。只有 Norby 核對實際退款後才能標記已退款。客戶自行取消、正式提交後的退款尚未定義，不套用這項全退規則，由 Norby 人工處理。

## 主流程

建案／備料 → 報價 → 銀行轉帳 → Norby 確認入帳 → 人工審核（可補件）→ 官方驗證及必要簽署 → TPSI 正式提交 → 查詢可取得的進度 → Norby 人工取得及核對公司註冊證明書與商業登記證 → 平台交付。

拒絕分支：審核拒絕且未提交 → 待全額退款 → Norby 確認退款 → 已退款。

不得將 TPSI 回應空白、連線逾時或已收到提交收據直接視為公司成立。送出後結果不明須保留嘗試紀錄並核對，不能盲目重送。審核、簽署及提交均綁定同一份資料版本；內容改動須重新完成相關檢核。

## 工程邊界

- 保留多語言校驗庫；修正 JavaScript BRN 尾隨垃圾字元的錯誤接受。
- 合規指南作為有來源的參考內容，不能充當 KYC 通過或法律判定。
- 網站、API、MCP 共用案件服務；所有讀寫均檢查案件所有權與 actor 類型。
- OAuth 由維護中的函式庫提供 PKCE、精確 callback 比對及資源綁定。撤銷後的 token 不得繼續讀寫案件。
- 身分資料與文件加密保存；附件下載要重新驗證權限。官方簽署密碼不得出現在 agent、日誌或持久化資料中。
- 本地開發可使用單節點 SQLite；正式網站已部署至 Cloudflare Workers，使用 D1、私有 R2、Workflows、HTTPS、Email Sending 及獨立加密金鑰。備份與回復程序見 [部署文件](cloudflare-deployment.md)；TPSI 正式提交仍待官方驗收。

## TPSI 核實依據

官方 API v1.0.15（2026-10）：https://www.e-services.cr.gov.hk/static/docx/TPSI%20API%20Interface%20v1.0.15.docx

- 驗證、PIN 簽署、提交、預付款餘額與文件狀態接口。
- NNC1 驗證／提交可能需要 60–90 秒；使用背景任務及明確的結果未知狀態。
- 狀態包括 Lodged、Pending re-lodged、Re-lodged；已登記文件不再返回查詢結果。
- e-Drive 上傳後只能經官方網站完成該份表格提交，不能當作 TPSI 自動提交的中間站。
- 證書由 Norby 從官方平台人工取回、核對並交付。
- 測試帳戶僅用官方提供的虛構資料；測試環境只做基本語法檢查，不能驗證實際成立。

## 必須通過的驗收

1. 客戶和 agent 不能取得他人案件，亦不能確認收款、批准 KYC、退款或成立。
2. 三個幣別獨立定價、兩個收款主體正確；TWD 對兩項未稅費用合計計算 5%。
3. 憑證上傳不會自動入帳；審核拒絕建立等於實收款的退款義務。
4. 未入帳、未審核、未完成所需簽署、資料版本已變動時不能正式提交。
5. 重複請求及併發操作不能重複收款、退款或提交。逾時不自動重送。
6. 兩份證書齊全並經 Norby 核對後，才能標記設立完成。
7. 繁中／英文及手機操作都能完成主要流程；表單有明確錯誤、焦點及載入狀態。

部署網域及郵件服務已設定；尚需正式售價、分項金額、公司法定名稱及銀行資料、秘書與註冊地址、聯絡入口、TPSI 正式／測試帳戶與預付款帳戶、NNC1 參數及簽署的官方測試。未提供資料不得用虛構值向真實客戶收款或提交。
